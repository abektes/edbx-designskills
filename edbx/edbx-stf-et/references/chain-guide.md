# Chain Guide — How to Use the Five Tools Together

The Stanford Ethics Toolkit is designed as a chainable sequence. This guide documents how outputs flow between tools, how to enter the chain at different points, and how to facilitate the chain with a team.

---

## The Chain at a Glance

```
EXPLORE                     EVALUATE                    DECIDE
─────────────────────────────────────────────────────────────────
Future Story  →  Impacts Explorer  →  Ethics Frame  →  Ethics Gauge  →  Weighing Options
     ↓                ↓                    ↓                 ↓                 ↓
  Narrative        Impact map         9-section         4-dimension       Option comparison
  of impacts       with values        worksheet         assessment        + Future Direction
```

---

## What Carries Forward at Each Handoff

### Tool 1 → Tool 2 (Future Story → Impacts Explorer)

| From Future Story | Into Impacts Explorer |
|---|---|
| Action/creation (Spine 2) | Center node |
| Direct benefits and harms (Spines 3–4) | First-ring Effects |
| Cascading "In turn" consequences (Spine 5) | Second-ring Secondary Effects |
| Values touched (Spine 5) | Outer ring — Values Impacted |
| Mitigating action (Spine 6) | Flag as potential mitigation pathway |

### Tool 2 → Tool 3 (Impacts Explorer → Ethics Frame)

| From Impacts Explorer | Into Ethics Frame |
|---|---|
| Action/creation | Section 1 — Action/Creation |
| All effects (direct + secondary) | Sections 3 & 4 — Benefits and Harms |
| Values identified and linked to effects | Sections 2 & 6 — Values |
| Stakeholder groups and their differential impacts | Section 5 — Who Is Affected |
| Fairness patterns observed in the map | Section 5 fairness spectrum |

### Tool 3 → Tool 4 (Ethics Frame → Ethics Gauge)

| From Ethics Frame | Into Ethics Gauge |
|---|---|
| Action/creation | Gauge header |
| Benefits with extent dimensions (magnitude, scope, likelihood, duration) | Dimension 1 — How is it beneficial? |
| Harms with extent dimensions | Dimension 2 — How is it harmful? |
| Fairness assessment, distribution patterns | Dimension 3 — How fair is it? |
| Autonomy and dignity issues from values analysis | Dimension 4 — How empowering is it? |
| Bottom Line | Context for the overall Gauge synthesis |

### Tool 4 → Tool 5 (Ethics Gauge → Weighing Options)

| From Ethics Gauge | Into Weighing Options |
|---|---|
| Current situation context | Current Situation field |
| Hot spots (spectra marked negative) | Key ethical considerations per option |
| Knowledge gaps (things needing investigation) | Obstacles — Uncertainties section |
| Values prioritized (from Ethics Frame, confirmed by Gauge) | "What are you prioritizing?" section per option |
| Overall synthesis assessment | Grounds the Future Direction reasoning |

## Entering the Chain at Different Points

**Early ideation (entering at Tool 1 — Future Story)**
Use when: the team is just beginning to think about ethical implications, or when the design space is still open. Future Story's narrative format helps surface concerns without requiring prior analysis. Recommended for new projects and early-stage research.

**Mid-project (entering at Tool 2 — Impacts Explorer)**
Use when: the action or creation is defined, but the team needs to map its full range of effects before an evaluation. Requires knowing the action/creation and having some sense of who is affected.

**Evaluation stage (entering at Tool 3 — Ethics Frame)**
Use when: the team already has a clear picture of impacts (perhaps from prior research, user testing, or stakeholder feedback) and needs to structure ethical considerations and response planning. The Ethics Frame is the most versatile standalone tool.

**Audit or tracking (entering at Tool 4 — Ethics Gauge)**
Use when: a product or policy is live or near-launch and needs a systematic check against core ethical principles. The Gauge can be repeated over time to track changes in ethical performance.

**Decision point (entering at Tool 5 — Weighing Options)**
Use when: a decision between two or more options must be made and the team needs a transparent comparison framework. Works best when prior analysis (from Tools 1–4 or other sources) has already mapped the ethical landscape.

## Running the Chain With a Team

### Time Budgets

| Mode | Tools | Time |
|------|-------|------|
| Quick scan | Tool 3 or Tool 4 only | 20–30 minutes |
| Exploration session | Tools 1–2 | 45–60 minutes |
| Full evaluation | Tools 3–4 | 60–90 minutes |
| Decision workshop | Tools 3–5 | 90–120 minutes |
| Complete chain | Tools 1–5 | Half-day workshop (3–4 hours) |

### Facilitation Tips

**Solo use:** Complete each tool in writing before moving to the next. Resist the urge to skip ahead. The sequence is designed so that each tool surfaces content the next one needs.

**Team use:**
- Give participants individual time to complete each tool (or each section) before group discussion. Individual-first prevents anchoring on the first voice heard.
- Use the feed-forward sections explicitly — read them aloud before transitioning to the next tool to make the chain visible.
- In the Ethics Frame and Weighing Options, have each team member complete the values prioritization section independently, then compare. Differences in what people prioritize are the most valuable conversations.

**Asynchronous teams:**
- Complete Tool 1 and Tool 2 asynchronously (assign individual ownership).
- Synthesize the outputs together before starting Tool 3.
- Tools 3–5 benefit most from synchronous discussion, especially Sections 5–9 of the Ethics Frame and the Future Direction of Weighing Options.

### When to Loop Back

The chain is not strictly one-directional. Common loop-back triggers:

- Ethics Gauge reveals a knowledge gap → loop back to Impacts Explorer to map that gap
- Ethics Frame's "Who Is Affected" raises a group not considered in the Impacts Explorer → loop back and add them
- Weighing Options surfaces a third option not previously considered → add it and re-run the societal/organizational impact analysis
- The Future Direction is blocked by unresolved uncertainty → loop back to the Obstacles section and assign research
