# Related Methods — EDB Toolkit Connections

Bad Design Canvas is part of the Ethical Design Box (EDBX) skillset. It connects to other skills in specific, complementary ways.

---

## Companion Skill Relationships

### edbx-worrystorming
Worrystorming generates free-form worries across eight thematic clusters. Bad Design Canvas provides a structured 12-category taxonomy that forces systematic coverage. Worrystorming is generative and exploratory; Bad Design Canvas is comprehensive and taxonomic.
**Sequence:** Run Worrystorming to generate raw concerns, then Bad Design Canvas to ensure no category of harm is missed.

### edbx-inverted-behavior-model
The Inverted Behavior Model forecasts behavioral consequences — what users will actually do. Bad Design Canvas maps the broader social, environmental, and cultural consequences beyond individual behavior.
**Sequence:** Run the Inverted Behavior Model to understand behavioral outcomes, then Bad Design Canvas to map the societal consequences of those behaviors at scale.

### edbx-humane-design-guide
The Humane Design Guide maps exploitation across six human sensitivities (Attention, Emotional, Sensemaking, Decision-making, Social Reasoning, Group Dynamics). Bad Design Canvas covers a broader 12-category spectrum including environmental, economic, and cultural dimensions.
**Sequence:** Run the Humane Design Guide for sensitivity-specific analysis, then Bad Design Canvas for comprehensive consequence coverage.

### edbx-fair-patterns
Fair Patterns identifies and remediates dark UI patterns at the interface level. Bad Design Canvas identifies systemic consequences beyond the interface — business model harms, displacement, inequity.
**Sequence:** Run Bad Design Canvas to find systemic harms, then Fair Patterns to clean up any UI-level dark patterns in the solution.

### edbx-cider
CIDER surfaces exclusionary assumptions embedded in a design. Bad Design Canvas maps how those assumptions lead to inequity, exploitation, and stakeholder abandonment.
**Sequence:** Run CIDER to identify assumptions, then Bad Design Canvas to trace those assumptions to their consequences.

### edbx-normative-design-scheme
The Normative Design Scheme applies three ethical theory lenses (Virtue, Consequentialism, Deontology). Bad Design Canvas provides the concrete consequence taxonomy that consequentialist analysis should evaluate.
**Sequence:** Run Bad Design Canvas to identify consequences, then the Normative Design Scheme to evaluate them through ethical theory.

### edbx-pledge-works
Pledge Works formalizes ethical commitments. Bad Design Canvas `🔴 Significant` findings are natural inputs for what to pledge against.
**Sequence:** Run Bad Design Canvas first, then use the findings as the basis for design pledges.

### edbx-anotherlens
Another Lens surfaces internal biases and worldview assumptions. Bad Design Canvas reveals the external consequences those biases produce when embedded in a product.
**Sequence:** Run Another Lens for self-awareness, then Bad Design Canvas to trace biases to their real-world consequences.

## Future Method Connections

These methods are referenced in the source material and may be added to the EDBX skillset:

- **Ethics Canvas** — A related broad-spectrum canvas method with a different taxonomy
- **Judgment Call** — Provides structured decision-making for the hardest Bad Design Canvas findings, especially systemic ones that require a "do we build this?" verdict

## Recommended Sequences

**Comprehensive ethical audit:**
1. edbx-anotherlens (self-awareness and bias check)
2. edbx-cider (inclusion and assumption audit)
3. edbx-bad-design-canvas (comprehensive consequence mapping)
4. edbx-humane-design-guide (sensitivity exploitation analysis)
5. edbx-normative-design-scheme (ethical theory evaluation)
6. edbx-pledge-works (formalize commitments from findings)

**Pre-launch consequence review:**
1. edbx-worrystorming (generate raw concerns)
2. edbx-bad-design-canvas (systematic 12-category audit)
3. edbx-fair-patterns (UI-level dark pattern check)

**Early-stage concept stress test:**
1. edbx-anotherlens
2. edbx-bad-design-canvas (Steps 2–3 only: quick canvas + summary)

**Post-incident analysis:**
1. edbx-bad-design-canvas (retrospective mode: what would the canvas have caught?)
2. edbx-inverted-behavior-model (what behaviors drove the incident?)
3. edbx-pledge-works (commit to preventing recurrence)

## Bad Design Canvas as Consequence Infrastructure

Bad Design Canvas is Method #09 — one of the earliest methods in *Universal Methods of Ethical Design*. It is foundational infrastructure for ethical design practice: the broadest-spectrum consequence tool in the set (12 categories vs. Worrystorming's 8 cluster themes).

It answers the question: *"What are all the ways this product could be bad — before we find out the hard way?"*

The method is designed to be approachable and fast, not exhaustive. It should feel like a structured conversation, not a compliance exercise. The adversarial framing (`#breakmydesign`) is a feature — it asks designers to argue against their own work, which is where the most valuable insights emerge.
