# Checks: edbx-value-dams-and-flows (written before opening any output)

Source: Miller, Friedman, Jancke & Gill (2007), Value tensions in design, GROUP '07 (`miller2007value`; origin per `chivukula2021surveying` p. 30, row 2), a Value Sensitive Design method; listed as method 92 in Chivukula & Gray (2025) (row 17). The primary texts are paywalled and unread: the dam / flow / order definitions (rows 5-7) are `metadata only`, read only in the Wikipedia VSD summary (`wikipedia2026vsd`), and the survey text defines neither term (row 21). The checks below therefore rest on that secondary definition and are weaker than a primary-source check; they are the only published statement of the method's moves available. Skipped as adaptation: Hard / Soft / Weak dam tiers, Strong / Conditional / Contested flow tiers, Conflict Intensity Score, Power Asymmetry, redesign alternative, negotiation framing, "minimum viable ethics" floor, "What Would Have to Be True", Values Balance Statement, facilitation agenda, Dam-Flow Map table layout, the "Dam of Disagreement" / "Flow of Consensus" names, hashtags, See Also list, the Answer section, the Evidence Ledger, output formatting.

- D1: Treats a dam as a design option removed from the design space because even a small share of stakeholders strongly objects (a minority veto on strong objection), not because a majority votes against it (row 5).
- D2: Treats a flow as an option, among those left after the dams, that a substantial share of stakeholders find appealing and that is therefore emphasised (row 6).
- D3: Applies the two in order: dams first, then flows chosen only from the remaining options (row 7).
- D4: Works on design options or features (technical features and organisational policy) as the unit being filtered, i.e. starts from a list of candidate options and says which are dammed and which are flows (row 8).
- M1 (invented facts): states figures, research, incidents, quotes, users or system details about the user's situation that the prompt does not give, as real (not labelled assumption/example).
- M2 (misstated method): wrong origin or creators (not a 2007 Value Sensitive Design paper by Miller, Friedman, Jancke, Gill; e.g. claims it comes from hydrology or from "ethical design practice" or names another creator); defines a dam as a majority vote or a flow as pure majority support (conflicts with the only readable definition; unverified); or presents an edbx-only element as the method's own (Hard / Soft / Weak dams, Strong / Conditional / Contested flows, Conflict Intensity Score, "Dam of Disagreement" names as official).
